# 심판 평점 집계 규칙

See VAR가 팬 평가를 어떻게 숫자로 만드는지 정리한 문서입니다.
구현: `lib/utils/stats.ts` (규칙), `lib/services/round-referee-highlights.ts` (라운드 베스트/워스트), `lib/services/referee-rankings.ts` (시즌 랭킹).
상수를 바꾸면 사이트 전체가 같은 기준으로 바뀝니다. 테스트: `npm test`.

---

## 1. 화면에 보이는 평점 = 실제 평균

- 대상은 **노출 중(VISIBLE)인 평가**뿐입니다. 숨김·심의 중인 평가는 어떤 집계에도 들어가지 않습니다.
- 평가가 하나도 없으면 `0.0`이 아니라 `—`로 표시합니다.
- 화면의 "평점/AVG/평균"은 항상 단순 평균입니다. 아래의 보정 평점은 **순서를 정할 때만** 씁니다.

## 2. 보정 평점 (순위용)

평가가 적을수록 기준 평균 쪽으로 당겨서 비교합니다. 1명이 준 1점이 12명이 준 1.8점보다 "더 나쁜 심판"이 되지 않게 하기 위한 장치입니다.

```
보정 평점 = (기준 평균 × 가중치 + 평점 합) ÷ (가중치 + 평가 수)
```

| 범위 | 기준 평균 | 가중치 | 표본 적음 기준 | 쓰는 곳 |
|------|-----------|--------|----------------|---------|
| 라운드(경기) | 그 라운드·같은 역할의 전체 평균 | 3 | 평가 3명 미만 | 홈·경기 기록의 라운드 베스트/워스트, 전체 평점 표, 관리자 라운드 리포트 |
| 시즌 누적 | 집계 범위 전체의 평균 (시즌 랭킹은 선택한 시즌·리그·역할, 심판 목록은 전체 평가) | 10 | 평가 10건 미만 (랭킹에서는 순위 제외) | 시즌 심판 랭킹, 심판 목록의 평점 정렬 |
| 팀 팬 × 심판 | 그 팀 팬이 준 전체 평균 | 5 | 평가 5건 미만 | 팀 페이지 "팬들이 뽑은 심판 상성" |

평가가 쌓일수록 보정 평점은 실제 평균에 가까워집니다.

## 3. 라운드 베스트/워스트

- 한 경기에서 한 역할로 뛴 심판 한 명이 집계 단위입니다. 한 라운드에 두 경기를 맡으면 경기별로 따로 봅니다.
- 보정 평점이 가장 높은 심판이 최고점, 가장 낮은 심판이 최저점입니다. 동점이면 평가 수가 많은 쪽을 먼저 봅니다.
- VAR 2명처럼 같은 경기에서 같은 평가를 함께 받은 심판은 한 카드로 묶습니다.
- **평가받은 심판이 한 명뿐이거나 전원 동점**이면 같은 심판을 양쪽에 올리지 않습니다. 평균 3점 이상이면 최고점에만, 미만이면 최저점에만 표시합니다.
- 평가 3명 미만이면 카드와 표에 `표본 적음`을 붙입니다.

## 4. 팬 시점과 균형 평점

평가를 남긴 시점의 응원팀(스냅샷)으로 시점을 나눕니다.

- 홈팀 팬 / 원정팀 팬 / 제3자 팬(두 팀 모두 아님) / 응원팀 미설정
- **균형 평점** = 홈팀 팬·원정팀 팬·제3자 팬 평균을 같은 비중으로 평균한 값.
  진 팀 팬이 몰려서 평가한 경기처럼 한쪽으로 쏠린 표본을 걸러서 볼 때 씁니다.
  한 시점의 평가만 있으면 표시하지 않습니다(`—`). 응원팀 미설정 평가는 균형 평점에서 제외합니다.
- 홈·원정 팬 평균 차이가 1점 이상이면 관리자 라운드 리포트의 "체감 격차가 큰 판정"에 올라갑니다.

## 5. 파생 통계 테이블

`RefereeStats`, `RefereeTeamStat`은 원본(`MatchReferee`, `RefereeReview`)에서 계산한 값을 저장해 둔 테이블입니다.
`RefereeStats.avgRating`은 보조 값이며, 화면의 평점은 항상 `RefereeReview`에서 직접 계산합니다.

- 평가 작성·수정, 숨김·재노출, 회원 탈퇴 때 `syncRefereeRatingStats`(`lib/referee-stats-sync.ts`)가 다시 맞춥니다.
- 값이 어긋났다고 의심되면 원본에서 통째로 다시 만듭니다.

```bash
npm run db:rebuild-referee-stats              # 차이만 출력 (DB 변경 없음)
npm run db:rebuild-referee-stats -- --apply   # DB에 반영
```

> 2026-10 이전에는 숨김 처리된 한줄평이 팀별 팬 평점에 남아 있었습니다. 이 수정이 배포된 뒤 한 번 `--apply`로 재집계하는 것을 권장합니다.
