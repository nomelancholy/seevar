# 새 시즌 관리자 설정 순서

팀과 심판의 기본 정보는 한 번만 등록하고, 시즌별 소속과 활동 여부만 매년 관리합니다.
과거 시즌의 경기, 결과, 심판 배정, 평점은 새 시즌 설정의 영향을 받지 않습니다.

## 2027 시즌을 여는 예시

1. `/admin/structure`에서 `2027` 시즌을 추가합니다.
2. 2027 시즌에 기존 시즌과 같은 슬러그의 리그를 추가합니다. 예: `k-league-1`, `k-league-2`.
3. `/admin/season-rosters`에서 2027 시즌을 선택합니다.
4. `2026 명단 복사`를 눌러 팀과 활동 심판을 복사합니다.
5. 승격·강등 팀의 리그를 변경하고, 신규·제외 심판을 체크합니다.
6. `/admin/structure`에서 라운드를 만들고 `/admin/matches`에서 일정을 등록합니다.
7. `/admin/referee-assignments`에서 해당 시즌 활동 심판만 경기별로 배정합니다.

## 데이터 보존 원칙

- 팀의 리그 이동은 선택한 시즌의 소속만 바꿉니다.
- 이미 해당 시즌 경기가 있는 팀은 경기 리그와 다른 리그로 이동하거나 미소속 처리할 수 없습니다.
- 이미 해당 시즌 경기에 배정된 심판은 활동 명단에서 제외할 수 없습니다.
- 크롤러나 관리자가 실제 경기 심판을 배정하면 그 심판은 해당 시즌 활동 명단에 자동 포함됩니다.
- 시즌 전체 복사는 대상 시즌에 경기가 생기기 전에만 할 수 있습니다.
